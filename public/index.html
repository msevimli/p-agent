Skills

Workspace skills live in skills/ and can be enabled or disabled. The agent can discover, run, and author new skills here when asked.

Library

Persistent file library — documents, code, and assets you can attach to chats or let the agent read. Files are stored in data/library/. Use the paperclip in the chat input to attach any of these files to your next message.

Models

Configure one or more LLM endpoints. The active model is used for the next chat message. Add a local llama.cpp server (endpoint http://127.0.0.1:PORT) or a remote OpenAI-compatible endpoint with an API key.

Automations

Run workspace scripts, skills, or LLM prompt tasks on a schedule. Cron uses 5 fields — minute hour day-of-month month day-of-week (e.g. 0 9 * * 1-5 = weekdays at 09:00). Any rule can also be triggered manually with Run now.

New automation

5 fields: minute hour day-of-month month day-of-week. Examples: */15 * * * *, 0 3 * * *, @daily.
